# eNet App — основа приложения

Стартовый проект Flutter под **Windows и iPhone (iOS)**. Единая визуальная система eNet: глубокий тёмный фон, «матовое стекло», голубой неон, исходная аватарка команды, плавные пружинные анимации. Проект **не привязан** ни к игре, ни к модификациям или сервисам.

## Дизайн

- **Стекло.** Карточки, боковая панель и нижняя панель — матовое стекло с размытием фона (`Glass`), как в visionOS / Fluent Acrylic.
- **Живой фон.** Медленно дрейфующее свечение и орбита, бесшовный цикл (`AmbientBackground`).
- **Навигация.** На ПК — стеклянная боковая панель со скользящей подсветкой, на телефоне — плавающая нижняя панель. Выбранный пункт плавно «переезжает».
- **Микроанимации.** Каскадное появление элементов (`Reveal`), нажатие с уменьшением и тактильным откликом (`Pressable`), подъём карточек при наведении мыши, раскрытие полей в форме, пружинный переключатель.
- **Типографика.** Крупные заголовки с плотным трекингом, приветствие по времени суток, дата.
- **Доступность.** Все бесконечные анимации останавливаются, если в системе включено «уменьшить движение».

## Что уже сделано

- Адаптивные экраны **Вход / Регистрация / Восстановление пароля** с проверкой полей.
- Главная страница после входа, боковая навигация на ПК и нижняя панель на телефоне.
- Разделы: Главная, Уведомления, Профиль, Настройки.
- Анимированный орбитальный фон с учётом системной настройки уменьшения анимаций.
- Настройка включения/выключения динамического фона.
- Авторизация вынесена в интерфейс `AuthRepository`, чтобы подключить сервер без переписывания UI.

## ВАЖНО: авторизация сейчас демонстрационная

`DemoAuthRepository` принимает любой корректно введённый email и пароль (от 8 символов). **Реальных аккаунтов не создаёт**, не сохраняет пароли, не отправляет письма и не является системой безопасности. Состояние существует только пока приложение открыто. Это необходимо заменить на настоящую серверную авторизацию до выпуска.

## Запуск

Установите Flutter SDK **3.27 или новее** (Dart 3.6+) и выполните в корне проекта:

```bash
flutter create --platforms=windows,ios,web .
flutter pub get
flutter run -d windows
```

На macOS с Xcode:

```bash
flutter run -d ios
```

`flutter create` создаёт нативные папки проекта, которые в этом минимальном стартовом архиве не включены. На Windows нельзя собрать iOS-приложение без macOS/Xcode.

## Структура

- `lib/core/theme` — палитра, параметры движения, тема.
- `lib/core/widgets` — `Glass`, `Pressable`, `Reveal`, кнопки, переключатели, логотип, аватар, фон.
- `lib/features/auth/domain` — контракт авторизации.
- `lib/features/auth/data` — безопасно обозначенный демо-адаптер.
- `lib/features/auth/application` — управление сессией.
- `lib/features/auth/presentation` — формы входа и регистрации.
- `lib/features/shell/presentation` — главное меню и базовые экраны.
- `assets/enet_logo.jpg` — предоставленная пользователем аватарка eNet.
